# スワイプ・ランデブー！ (SWIPE RENDEZVOUS!)

**マッチングアプリ × 3D歩道アクション**（Three.js + TypeScript + Vite + Web Audio API）

左画面でマッチングアプリのプロフィールを左右にスワイプしながら、右画面の3D歩道で即座に歩いてくるマッチング相手を見極めて捌く、**左右常時同時進行の3Dスコアアタックゲーム**です。

## 主な特徴

- **左右二分割・常時同時進行ゲームループ**
  - **左画面（PairWalk）**: 写真・自己紹介・タグ・目印から当たりの可能性を予想して右スワイプ（会う）／左スワイプ（会わない）。スワイプ自体は±0点。
  - **右画面（3D歩道アクション）**: 右スワイプした相手が即座に歩道奥（遠景）に登場。接近すると本性・固有アクション（フェーズ2）が判明し、**当たり（+1,000点〜＋連続誠実コンボ＆ダブルランデブー）**には接触、**外れ（-600点）**・**業者（-1,200点）**は左右移動で回避します。
  - **見逃し・回避はすべて±0点**: 当たりを見逃しても減点なし。一般通行人は進路妨害（減速・ノックバック、連続衝突防止の無敵時間付き）のみでスコア変化なし。
- **60名の個性豊かなキャラクターと21種の3D行動アーキタイプ**
  - 添付資料（60例のリサーチ・着想集）をベースに、当たり22名・外れ19名・業者19名の全60名を実装。
  - 傘を広げて待つ、歩幅を合わせる、歩きスマホで斜め横断、写真パネルを裏返す「別人でした」、配信リグ `[REC LIVE]`、巨大な暗号資産上昇チャート、扇状の契約書、背後から飛び出す「師匠」、料金表なしネオンBAR看板、ケーキ箱が変形するピラミッド模型など、視覚的に笑えて納得感のある3D演出を実装。
  - 2Dプロフィール写真（AI生成背景6種＋3D外見連動ポートレート合成）と3Dアバターが服装・髪型・持ち物で一致（写真詐欺キャラは意図的なギャップ演出あり）。
- **2段階の難易度（ふつう / 難しい）＆ ラスト週末RUSH**
  - 1プレイ75秒。終盤にテンポ＆BGMピッチが上がるRUSHへ突入。自己ベスト記録・素早いリトライ・『今日のマッチング振り返り図鑑』を搭載。
- **プロシージャルWeb Audio音響（BGM/SE個別ON・OFF）**
  - 渋谷シティポップ／ファンク調BGMシーケンサー、コンボ連動の接触効果音などすべてWeb Audio APIで生成。タイトル画面およびプレイ中HUDでBGMとSEを個別にON/OFF可能。
- **PC・スマートフォン両対応（同時入力独立設計）**
  - **PC**: 左画面＝マウススワイプ（またはボタン/`Q`/`E`）、右画面＝`A`/`D`または左右矢印キー。
  - **スマホ**: 横画面（標準・横2カラムカード最適化）および縦画面の両方で、独立した `pointerId` により左親指スワイプと右親指ドラッグを同時操作可能。

## セットアップ＆起動

```bash
npm install
npm run dev
```

プロダクションビルド：

```bash
npm run build
npm run preview
```

自動検証（Playwright）：

```bash
node scripts/verify_game.mjs
```
